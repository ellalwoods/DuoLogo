# Duo Logo — Design B: The Lab

> The same course, the same lesson loop, the same questions as Design A. A different world: **Australian IP law as a science.** Clean, precise, systematic, with a periodic table for a home screen.

---

## 1. The idea

Design A (*The Bower*) is warm and story-led. Design B is for the part of you that likes things **organised**: law as a system of elements, tests as experiments, cases as published results, and memory as something you can measure.

Three scientific ideas carry the whole app:

| Science | In the app |
|---|---|
| **The periodic table** | The syllabus. Every unit is an element, placed by right and by stage |
| **Reactions** | Causes of action. Elements combine into liability; defences inhibit the reaction |
| **Half-life and the forgetting curve** | Spaced repetition. What you learn decays at a measurable rate, and review resets it |

## 2. Home: the Periodic Table of IP

The home screen is a periodic table, and it *is* the syllabus.

- **Columns (groups) are the rights:** Copyright · Trade marks · Passing off & ACL · Patents · Designs · Confidential information.
- **Rows (periods) are the Five Sticks:** 1 What? · 2 How? · 3 Whose & how long? · 4 Breach · 5 Escape.
- Foundations sit as a top row. Enforcement and the specialist rights sit below as a separate block, like the lanthanides. **IP in practice** (Chapter 9) is the last block, **Field work**: each unit is a field experiment built around a realistic matter, and it unlocks once the core elements are discovered.

So any element's position tells you what it is. *Patents, row 2* is how you get a patent. *Trade marks, row 4* is trade mark infringement. Reading down a column teaches a whole right. Reading across a row compares every right at the same stage.

Each tile is styled like a real element tile:

```
┌─────────────────┐
│ 23        s 41  │   ← atomic number (course order) · key section
│                 │
│       Dt        │   ← symbol
│ Distinctiveness │   ← name
│ ▓▓▓▓▓▓▓░░  t½ 9d│   ← memory strength · current half-life
└─────────────────┘
```

Example symbols: **Or** Originality · **Sp** Substantial part · **Au** Authorisation · **Fd** Fair dealing · **Dt** Distinctiveness · **Ds** Deceptive similarity · **Ut** Use as a trade mark · **Mm** Manner of manufacture · **Nv** Novelty · **Is** Inventive step · **Iu** Informed user · **Sq** Quality of confidence.

**Tile states:**
- **Undiscovered:** an outline with a "?" (like the gaps Mendeleev left for elements not yet found).
- **Discovered:** filled in its group colour.
- **Decaying:** the colour fades as the memory weakens. A tile due for review glows faintly, like something radioactive.
- **Stable:** reviewed many times; a thick border marks a long half-life.

The table fills as you learn. Seeing the gaps is half the motivation.

## 4. Lessons as a lab notebook

Lesson cards sit on **graph paper**, numbered like figures in a paper.

- **Rule cards** read like definitions in a textbook: a bold term, then a precise definition, with the section in the margin.
- **Statute cards** look like an annotated specimen under a microscope: the provision's text, with each element circled and numbered (①②③) and a note beside each.
- **Test cards** are **flowcharts**, like a diagnostic key in a field manual.
- **Case cards are experiments**, written up in scientific format:

```
EXPERIMENT 14 · IceTV v Nine Network · [2009] HCA 14
HYPOTHESIS   Taking time & title info infringes copyright in a TV schedule
METHOD       IceTV checked its own guide against Nine's published schedules
RESULT       ✗ Hypothesis rejected (6–0)
DISCUSSION   Effort must be directed to expression, not programming decisions
REPLICATION  Followed: Telstra v Phone Directories (2010) · Acohs (2012)
```

The **Replication** line shows how later cases have treated the decision (followed, applied, distinguished, doubted, overruled), drawn as a small citation network you can tap through.

- **Critique cards** are styled as a "peer review": arguments for and against, with reform reports as citations.
- **Trap cards** are lab safety warnings (the hazard-label triangle): *"Do not cite Desktop Marketing as current law."*

## 5. The question formats, re-themed

Identical mechanics to Design A. Only the skin changes.

| Design A | Design B | What you do |
|---|---|---|
| Tag the Right | **Spectroscopy** | A scenario passes through a prism; drag each spectral line (a fact) to the element it reveals |
| Examiner's Stamp | **Assay** | Test a sample (a mark, design or claim) against each criterion in turn. Each test reads ✓ or ✗ on a readout, then you give the result and the ground |
| Build the Bower | **Reaction** | Combine the right elements into a balanced equation to produce liability. Add a defence and it acts as an **inhibitor** |
| Copycat? | **Similarity index** | Overlay two works or marks; set a 0–100 similarity reading, then say what the law cares about |
| The Clock | **Timeline** | Events on a calibrated time axis: priority dates, grace periods, durations |
| Case Snap | **Citation network** | Connect cases with labelled edges: *follows*, *distinguishes*, *overrules* |

**Reaction** is the signature game. For example:

```
Reputation + Misrepresentation + Damage  ──▶  PASSING OFF
Specificity + Confidentiality + Obligation + Misuse  ──▶  BREACH OF CONFIDENCE
Use as a TM + Deceptively similar + Same goods  ──[ s 122(1)(b) good-faith descriptive use ]──▶  ✗ no infringement
```

Missing a reactant? The reaction fizzles. Added a fake one (say, "intention to deceive" for passing off)? It's flagged as a contaminant.

### Chapter problem questions: the Lab Report
The IRAC structure as a lab report:
1. **Observations:** mark the facts that matter.
2. **Questions:** name the issues.
3. **Method:** pick the law (sections, tests, cases).
4. **Results:** apply each element to the facts.
5. **Conclusion:** likely outcome and remedies.

Tap mode or write mode, then compare with a model answer and a marking checklist.

## 6. Review: Half-life

Spaced repetition, shown honestly as the science it is: Ebbinghaus's **forgetting curve**.

- Each element has a **half-life**: how long until your recall probability halves. A new element starts at about 1 day.
- Every correct review **extends the half-life** (1 d → 3 d → 7 d → 16 d → 35 d → 90 d). A wrong answer shortens it.
- The Half-life screen shows your elements on a **decay chart**: a line per element sloping down, with today marked. Anything under the threshold is due.
- One button: **Stabilise**, which reviews everything that's decaying.
- A single number on the home screen: **course retention %**, your estimated recall across everything you've learned. Watching it go up before an exam is very motivating.

## 7. Visual language

### Look: *a modern lab notebook*
Clean, white, gridded, precise. Graph paper, fine hairlines, tabular numbers, small labelled diagrams. Think a scientific journal crossed with a well-designed periodic table poster. No mascot. The **table** is the identity.

### Colour: one colour per group (right), like element families
- **Ink** `#111418` on **lab white** `#FAFBFA`, with a pale **graph grid** `#E3EDF0`.
- Groups:
  - Copyright: **cobalt** `#2F6FDB`
  - Trade marks: **amber** `#E08A1E`
  - Passing off & ACL: **coral** `#E0614A`
  - Patents: **emerald** `#1E9E6A`
  - Designs: **violet** `#8A5CD6`
  - Confidential information: **slate** `#4F6A7A`
  - Foundations and enforcement: **graphite** `#7A8088`
- **Signal highlighter** `#D9F25C`: the one thing to focus on right now (today's element, the next step in a test).
- Decay is shown by **desaturation**: knowledge you're losing literally greys out.

### Type
- **IBM Plex Sans** for text, **IBM Plex Mono** for symbols, section numbers, citations and data. Tabular numerals everywhere.
- Element symbols in a heavy weight, as on a periodic table.

### Motion and touch
- **Discovery:** a new element drops into its empty slot on the table with a small flash and a tick.
- **Reaction:** reactants slide together, the arrow fills, and the product appears. A missing reactant makes the arrow stall.
- **Assay:** each criterion runs like an instrument reading, ticking across its gauge.
- **Decay:** tiles fade slowly; reviewing makes them snap back to full colour.

### Voice: the precise, curious lecturer
Clear, exact, with dry footnote humour.¹ *"Result: hypothesis rejected. Six judges, zero dissents. Nine's programming decisions were business, not authorship."*

¹ *Footnotes are where the jokes live. Like real academic writing.*

## 8. Choosing between A and B

| | A · The Bower | B · The Lab |
|---|---|---|
| Feel | Warm, playful, Australian, story-led | Cool, precise, systematic |
| Home | One illustrated scene | The periodic table: the whole course at a glance |
| Progress you see | Sticks and treasures | Filled elements and a retention % |
| Best for | Daily habit and delight | Seeing structure, comparing rights, exam prep |
| Build effort | More illustration | Mostly layout and data viz: quicker to build well |

**Recommendation:** B for a full course. The periodic table makes the structure of 81 units visible in one screen, and the row-by-row comparison is exactly how IP exams test you. A's warmth could live on in small touches (the voice, the "Raid" nudges) if you want both.
